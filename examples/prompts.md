# Example prompts

These are task patterns. Replace placeholders with actual project context; do not invent supporting evidence.

## A bounded fix

```text
Use Formsemble. On the attached screen, the main action label is clipped on narrow devices. Fix only that problem, preserve the existing action, and check the affected layout and nearby behavior.
```

## Improve a complete flow

```text
Use Formsemble to improve the equipment-return flow in this project. First understand the current user, objects, rules, and completion state. Preserve the working integration. Implement the requested flow and its relevant error and empty states, then report which checks were actually performed.
```

## A new visual direction

```text
Use Formsemble to create a distinctive visual direction for this product. Work from the supplied brief and references. Compare two meaningful approaches using the same representative content, recommend one, and implement it unless an essential preference remains unresolved.
```

## Audit without edits

```text
Use Formsemble to audit these screens. Do not change files. Prioritize findings by their effect on the main task. For each material issue, identify the location, observation, evidence, consequence, correction, and recheck condition. Separate source findings from rendered or runtime observations.
```

## Hand off a repaired flow

```text
Use Formsemble to hand off the repaired appointment request form. Link the current narrow-width capture and runtime notes for the rejected submission, retained field values, and successful retry. Record which files and states the next reviewer should recheck if shared styles change. Keep untested assistive-technology behavior visible.
```

## Correct a misunderstood product

```text
Use Formsemble. The earlier draft misunderstood the user: this screen is for venue staff admitting attendees, not for attendees buying tickets. Update the product understanding, identify which decisions depend on that correction, and repair the affected flow while retaining valid unrelated work.
```

## Create a design-system increment

```text
Use Formsemble to standardize the existing form components. Reuse the current stack. Define semantic tokens, required variants and states, content guidance, and representative examples. Identify affected consumers and keep the migration limited to this component family.
```

## Work with limited tools

```text
Use Formsemble to improve this interface with the capabilities available in this session. Continue useful work if a renderer or independent agent is unavailable, and clearly identify what remains unverified. Do not change tool permissions or install unrelated services.
```
